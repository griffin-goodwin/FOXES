# Citing FOXES

The original FOXES method is described in our paper. For the updated
uncertainty checkpoint and its held-out evaluation, see
[Models and Checkpoints](models.md) and [Results](results.md).

> Goodwin, G. T., March, A. J., Biradar, J., Schirninger, C., Jarolim, R.,
> Vourlidas, A., Sadykov, V. M., & Pratt, L. (2026). Improving Solar Flare Soft
> X-Ray Classification with FOXES: A Framework for Operational X-Ray Emission
> Synthesis. *The Astrophysical Journal*, 1003(1), 48.
> [doi:10.3847/1538-4357/ae5e4a](https://doi.org/10.3847/1538-4357/ae5e4a)

If FOXES helps your work, please cite the paper:

```bibtex
@article{Goodwin_2026,
    title     = {Improving Solar Flare Soft X-Ray Classification with FOXES:
                 A Framework for Operational X-Ray Emission Synthesis},
    author    = {Goodwin, Griffin T. and March, Alison J. and Biradar, Jayant and
                 Schirninger, Christoph and Jarolim, Robert and Vourlidas, Angelos and
                 Sadykov, Viacheslav M. and Pratt, Lorien},
    journal   = {The Astrophysical Journal},
    volume    = {1003},
    number    = {1},
    pages     = {48},
    year      = {2026},
    publisher = {American Astronomical Society},
    doi       = {10.3847/1538-4357/ae5e4a}
}
```

If you use the code or data directly, you can cite the software as well:

```bibtex
@software{FOXES,
    title           = {{FOXES: A Framework For Operational X-ray Emission Synthesis}},
    institution     = {Frontier Development Lab (FDL)},
    repository-code = {https://github.com/griffin-goodwin/FOXES},
    version         = {v2.0.4},
    year            = {2026}
}
```
