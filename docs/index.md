# FOXES

```{container} foxes-subtitle
Framework For Operational X-ray Emission Synthesis
```

FOXES uses seven-channel SDO/AIA images to predict full-disk solar soft X-ray
flux and each image patch's contribution to that total.

Start with [Getting started](python_api.md) to install the package and make
one prediction. [Models and checkpoints](models.md) lists the available weights,
and [Results](results.md) shows the saved evaluation.
